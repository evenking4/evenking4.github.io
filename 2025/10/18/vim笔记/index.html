vim笔记

一般指令模式

  • <Ctrl> + f：向下移动一页
  • <Ctrl> + b：向上移动一页
  • [n]<space>：光标移动n个字符
  • 0：移动到这一列开头
  • $：移动到这一列最后一个字符
  • G：移动到文件最后一列
  • [n]G：移动到文件的第n列
  • gg：移动到文件的第一列，相当于1G
  • [n]<Enter>：光标向下移动n列
  • /[word]：向下搜索第一个word的字串，按n继续搜索，按N反向搜索
  • ?[word]：向上搜索第一个word的字串，按n继续搜索，按N反向搜索
  • :[n1],[n2]s/[word1]/[word2]/gc：在n1行与n2行之间寻找word1这个字串并用word2替换
  • x，X：x为向后删除一个字符，X为向前删除一个字符
  • [n]x：向后连续删除n个字符
  • dd：删除光标缩在的一行
  • [n]dd：删除光标所在的向下n行
  • d1G：删除光标所在行到第一行的所有数据
  • dG：删除光标所在行到最后一行的所有数据
  • d0：删除光标所在的字符到行首的所有数据
  • d$：删除光标所在的字符到行尾的所有数据
  • yy：复制光标所在的那一行
  • [n]yy：复制光标缩在的向下n行
  • y1G：复制光标所在的行到第一行的所有事护具
  • yG：复制光标所在的行到最后一行的所有数据
  • y0：复制光标所在的那个字符到行首的所有数据
  • y$：复制光标所在的那个字符到行尾的所有数据
  • p，P：p为将已复制的数据粘贴在光标的下一行上，P为将已复制的数据粘贴在光标的上一行上。
  • J：将光标所在行与下一行合并
  • u：撤销上一个动作
  • <Ctrl> + r：重做上一个撤销
  • . ：重复上一个动作

编辑模式

进入编辑模式的指令：i，I，a，A，o，O，r，R，一般用i即可。注意，r和R会进入取代模式，r只会取代所在那个字符一次，R会一直取代光标所在的文字。

按下<Esc>退出编辑模式，返回一般指令模式

指令列命令模式

  • :wq!：w为保存，q为退出，!表示强制

  • :w [filename]：另存为filename文件

  • :r [filename]：将filename的内容加到当前光标的后面

  • :[n1],[n2] w [filename]：将n1到n2行的内容存储为filename文件

  • :! [command]：暂时离开vim并执行命令command

  • :set nu：显示行号

  • :set nonu：取消显示行号

vim的额外功能

多文件编辑

同时打开多个文件：vim test1.txt vim test2.txt

  • :n：编辑下一个文件
  • :N：编辑上一个文件
  • :files：列出目前vim打开的所有文件

多窗口功能

  • :sp [filename]：在新窗口打开filename，如果没有指定filename，则会默认打开当前编辑的文件
  • <Ctrl> + w + <↓ or j>：光标移动到下方窗口
  • <Ctrl> + w + <↑ or k>：光标移动到上方窗口

关键词补全功能

  • <Ctrl> + x -> <Ctrl> + n：根据当前文件的内容文字进行补全。
  • <Ctrl> + x -> <Ctrl> + o：根据当前文件的扩展名，以vim内置的关键字进行语法补全。

~/.vimrc：该文件可以在每次打开vim时预先启动一些设置。
